## My Idea of Information

In this project, I consider information as a resource that allows a system to resist or reverse an increase in entropy.

A system that becomes disordered usually cannot return to its original state only by reversing the direction of time in a simple way. To reproduce the previous state, detailed information about the microscopic history of the system is necessary.

I use a random-walk model in which particles spread from an initially ordered position. During the forward process, the entropy of the particle distribution increases. If the particles continue moving randomly, the original state is not recovered. However, if every previous movement is recorded and applied in reverse order, the particles return to their initial positions and the entropy decreases.

Therefore, I define information not only as a reduction of uncertainty, but also as stored knowledge that can guide a system from disorder back toward order.
# entropy-reversal-information
A Python project exploring information as a resource for reversing entropy increase.
